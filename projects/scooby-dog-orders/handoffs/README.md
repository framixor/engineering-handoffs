# Historical handoffs

Dated directories in this folder are immutable historical evidence. Their baselines, patches and
acceptance criteria describe the state at publication time and may be superseded by current product
work.

Do not edit a dated package. Do not execute it merely because it is complete or visually approved.
A historical handoff is active only when `../CURRENT.md` points to it explicitly. Otherwise use it
only for audit/reconciliation and preserve current remote work.

The package `2026-08-16-atendimento-cozinha/` is preserved intact and is not the current slice.
